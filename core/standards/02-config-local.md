## Estándar 2: La config de Claude Code es local

`.claude/` (settings, skills, agents, commands, context) es tooling local del
desarrollador: **no se commitea**, cada proyecto la ignora en `.gitignore`.
Lo que sí es del proyecto (decisiones, specs) vive en `docs/`.
